# Creatively Feedback

Formulário interativo de avaliação para os projetos **Monthly Colors** e **Chromatic Void**.

## Fluxo

1. O visitante escolhe o projeto.
2. Informa nome, e-mail, cidade e estado.
3. Responde perguntas gerais e específicas.
4. Escreve os pontos positivos e as melhorias.
5. Revisa e autoriza o uso dos dados antes de enviar.

O visual muda automaticamente para acompanhar a personalidade do projeto selecionado.
